# Bestman Consult Ltd Website

A modern and responsive corporate website built for **Bestman Consult Ltd**, showcasing expertise across **Construction**, **Engineering**, **Surveying**, and **Mining Services**.  
The site is designed to provide a clean user experience, structured information flow, and visual presentation of the company’s capabilities and projects.

---

## 🚀 Technologies Used

| Technology | Purpose |
|-----------|---------|
| **React** | Frontend UI framework |
| **Vite** | Fast build and development tooling |
| **Styled Components** | Component-level styling and theming |
| **React Slick** | Smooth carousels and slider interactions |
| **JavaScript (ES6+)** | Application logic and interactivity |

---

## ✨ Key Features

- Fully responsive UI for Desktop, Tablet, and Mobile screens
- Animated **Hero Header Slider** with call-to-action buttons
- Team member profile showcase section
- Projects and services presentation areas
- Smooth scrolling navigation and visual transitions
- Contact section & branded footer layout
